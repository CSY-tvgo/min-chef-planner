# Min Chef（敏捷厨师）

一个面向家庭宴席准备的静态厨房排程工具。以时间为纵轴、厨房器具为横向泳道，帮助安排菜品步骤，直观看到器具占用和并行操作。

## 功能

- 添加、编辑、完成和删除烹饪步骤
- 在最后一个器具右侧添加器具；点击器具表头编辑名称、图标、容量或删除器具
- 器具容量可选 1、2、3 道菜或不限（默认）；同一时段按不同菜品计数，超限步骤标红并提示，不删除或阻止保存排程
- 一个步骤可以同时关联多个器具，一个器具也可以服务多个步骤
- 可通过 👨🏻‍🍳、👩🏻‍🍳 图标添加人员；步骤中的“参与人力”与“使用器具”分栏显示，可勾选多位已有人员，也可不选
- 厨师拥有独立时间轴列并沿用容量设置；参与人员与器具一同保存，人员改名或删除会同步更新关联
- 按时间查看并行任务；同一器具的同时段步骤分列显示，互不遮挡
- 最左侧“无器具”列显示未选择任何器具或人员的步骤
- 同一道菜的步骤只连向开始前已结束的最近步骤；同时结束的前序可汇合，多器具可分叉，忽略人员列；筛选隐藏步骤时不会跨过它们补画连线
- 数据自动保存在浏览器 `localStorage`，无需导出文件；底部说明与自动保存提示合并，保存异常仍会明确提示
- 支持手机横向滚动和电脑大屏查看
- 器具列默认约占可用宽度的四分之一，拖动表头右侧边缘调整列宽并自动保存；并行步骤只缩小卡片，不扩宽列
- 拖动整个器具表头或 ⠿ 左右排序，轻点打开设置；也可在设置中点“向左 / 向右”，靠近边缘自动横向滚动，支持键盘左右键和 Esc 取消
- 器具、菜品和步骤名称均可留空；未命名器具的表头只显示大图标
- 时间轴下方的齿轮时钟图标可设置起止时间、每屏小时数（默认 2.5 小时）及拖动步进（1/5/10/15/30 分钟，默认 5）；范围外的步骤仍可从菜单编辑
- 拖动卡片上的 ⠿ 整体移动，上下边缘调整起止时间（按已设置的步进）
- 右上角菜单首页只列菜品和完成进度；点开菜品管理步骤、改名或删除菜品
- 菜品内的步骤按时间排序，可直接勾选完成；添加步骤预填上一条的结束时间
- 保存、取消或按 Esc 退出步骤编辑后回到菜品页；时间轴范围外或未分配器具的步骤也可编辑
- 已有缓存自动迁移到菜品分组，未命名菜品可独立保留，空菜品也会保存
- 删除器具会解除关联，保留步骤；可在编辑框删除步骤

## 设备间传输

打开“菜单 → 导入 / 导出”，点击“生成并复制排程文本”。压缩文本以 `MC1.` 开头，不生成文件；也可长按文本手动复制。

在另一台设备粘贴文本并点击“检查导入内容”，核对摘要后点击“替换当前排程”。导入前建议先导出原排程备份。菜品、步骤、人力、器具顺序/列宽/容量、时间轴和步进设置都会转移；导入采用整体替换。损坏文本或缓存保存失败不会覆盖原排程。

压缩库随页面提供，不依赖浏览器原生压缩流接口。压缩、解压与校验均在当前浏览器内完成，不上传服务器。自动复制受限时可点“复制文本”重试，或手动选中文本复制。

## 本地开发

无需安装应用依赖或构建，在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

数据按浏览器和站点来源保存在 `localStorage`；清理站点数据会清除排程。保存受限或空间不足时，页面会显示“保存失败”。当前步骤时间限于同一天，结束时间必须晚于开始时间。

编辑 JavaScript、CSS 或压缩库后运行 `python3 tools/refresh_assets.py` 更新资源版本，避免浏览器继续使用旧缓存。

## 验证

```sh
node --check app.js
python3 -m pip install playwright==1.62.0
python3 -m playwright install chromium
CHROMIUM_PATH= python3 tests/browser_smoke.py
```

测试自带临时静态服务器和独立浏览器上下文，不修改已有排程。也可设置 `CHROMIUM_PATH=/usr/bin/chromium` 使用系统 Chromium。覆盖步骤增删改、未命名内容、多器具、并行布局、拖动、真实触控、缓存持久化及异常处理。


## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 后会自动部署到 GitHub Pages。首次使用时，在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**。

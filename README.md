# 宴席厨房排程

一个面向家庭宴席准备的静态厨房排程工具。以时间为纵轴、厨房器具为横向泳道，帮助安排菜品步骤，直观看到器具占用和并行操作。

## 功能

- 添加、编辑、完成和删除烹饪步骤
- 添加或删除厨房器具
- 一个步骤可以同时关联多个器具，一个器具也可以服务多个步骤
- 按时间查看并行任务；同一器具的同时段步骤分列显示，互不遮挡
- 数据自动保存在浏览器 `localStorage`，无需导出文件
- 支持手机横向滚动和电脑大屏查看
- 器具列默认约占可用宽度的四分之一，拖动表头右侧边缘调整列宽并自动保存；并行步骤只缩小卡片，不扩宽列
- 器具、菜品和步骤名称均可留空
- 可设置时间轴起止时间，一屏约显示 2～3 小时；范围外的步骤仍可从菜单编辑
- 拖动卡片上的 ⠿ 整体移动，上下边缘调整起止时间（5 分钟步进）
- 菜单可编辑全部步骤，包括早于时间轴起点或未分配器具的步骤
- 删除器具会解除关联，保留步骤；可在编辑框删除步骤

## 本地开发

无需安装应用依赖或构建，在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

数据按浏览器和站点来源保存在 `localStorage`；清理站点数据会清除排程。保存受限或空间不足时，页面会显示“保存失败”。当前步骤时间限于同一天，结束时间必须晚于开始时间。

## 验证

```sh
node --check app.js
python3 -m pip install playwright==1.62.0
python3 -m playwright install chromium
CHROMIUM_PATH= python3 tests/browser_smoke.py
```

测试自带临时静态服务器和独立浏览器上下文，不修改已有排程。也可设置 `CHROMIUM_PATH=/usr/bin/chromium` 使用系统 Chromium。覆盖步骤增删改、未命名内容、多器具、并行布局、拖动、真实触控、缓存持久化及异常处理。


## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 后会自动部署到 GitHub Pages。首次使用时，在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**。
